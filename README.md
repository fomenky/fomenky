## 🚀 Featured Projects

Each ships with a **live, browser-readable report** — no setup required.

### 1. [Financial Intelligence RAG Assistant](https://github.com/fomenky/financial-intelligence-rag)
Grounded, source-cited answers for brokers over financial news, prices, and SEC filings. Tuned the answering prompt with **DeepEval/GEPA optimization**, lifting grounded-answer quality **0.41 → 0.76** on a benchmark.
`RAG` · `LangChain` · `Chroma` · `GEPA/DeepEval` · `OpenAI`
📊 **[Live report](https://fomenky.github.io/financial-intelligence-rag/)** · 💻 [Repo](https://github.com/fomenky/financial-intelligence-rag)

### 2. [Last-Mile Delivery Exception — Multi-Agent System](https://github.com/fomenky/delivery-exception-multi-agent-system)
A **LangGraph** multi-agent pipeline that triages delivery exceptions end-to-end — resolve, escalate (deterministic rules), and notify — with PII enforced at the tool layer. **100% task / escalation / tool-call accuracy** on the benchmark.
`Multi-Agent` · `LangGraph` · `RAG` · `Guardrails` · `OpenAI`
📊 **[Live report](https://fomenky.github.io/delivery-exception-multi-agent-system/)** · 💻 [Repo](https://github.com/fomenky/delivery-exception-multi-agent-system)

### 3. [Hotel QnA — Deployable RAG Application](https://github.com/fomenky/hotel-qna-rag-app)
A source-grounded policy Q&A assistant for hotel staff, with a composite confidence score that routes low-confidence answers to manual lookup. Shipped as a **Flask + Streamlit app, containerized with Docker**.
`RAG` · `FAISS` · `Flask` · `Streamlit` · `Docker`
📊 **[Live report](https://fomenky.github.io/hotel-qna-rag-app/)** · 💻 [Repo](https://github.com/fomenky/hotel-qna-rag-app)

### 4. [Wind Turbine Drivetrain Fault Detection](https://github.com/fomenky/wind-turbine-fault-detection)
A **recall-tuned XGBoost** classifier that flags drivetrain faults from 10-minute SCADA sensor data across a 1,150-turbine fleet scenario — catching failures before they cascade into costly gearbox damage.
`Classification` · `XGBoost` · `Imbalanced Data` · `scikit-learn`
📊 **[Live report](https://fomenky.github.io/wind-turbine-fault-detection/)** · 💻 [Repo](https://github.com/fomenky/wind-turbine-fault-detection)
